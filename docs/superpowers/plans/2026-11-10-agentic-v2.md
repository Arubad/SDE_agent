# Agentic v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a measured tool-use agent loop over the MCP server, multi-hop and unanswerable evals with trajectory metrics, and prompt-injection defenses with a red-team eval.

**Architecture:** A new `backend/agent/loop.py` drives Claude Haiku 5.5 through MCP-discovered tools, returning passages as `search_result` blocks so answers keep API-native citations. `run_agent` dispatches premium requests to the loop or the existing pipeline by `AGENT_MODE`. Deterministic guards (`backend/agent/guard.py`) sit between the model and tools/output. New eval scripts compare the modes and measure attack success rate.

**Tech Stack:** Python 3.12, FastAPI, FastMCP 3.4 (in-memory client), `anthropic` 2.7 (`AsyncAnthropicFoundry`), Qdrant, pytest.

**Spec:** [docs/superpowers/specs/2026-11-10-agentic-v2-design.md](../specs/2026-11-10-agentic-v2-design.md)

## Global Constraints

- Work on a new branch `agentic-v2` off `main`. Do not push, deploy, or change Space secrets without the human's go-ahead.
- End every commit message with `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Run Python as `backend/venv/bin/python` from the repo root. Unit tests: `backend/venv/bin/python -m pytest backend/tests -q` (20 pass today).
- `backend/tests` stays offline: no network, no LLM, no Qdrant. LLM-calling code lives in `backend/eval` and is run by hand.
- Only Claude Haiku via Foundry (`config.HAIKU_MODEL`, helpers in `backend/core/llm.py`) for new LLM calls. No eval may call Gemini.
- Claude requests: never send `thinking`, `budget_tokens`, `temperature`, or assistant prefill. `tool_choice` is only `{"type": "auto"}` or `{"type": "none"}`. Message history is append-only; append `response.content` back unchanged.
- No new runtime dependencies. `fastmcp>=3.4,<4` stays (MCP 1.x: a tool's schema attribute is `inputSchema`).
- Public tier behaviour (one Gemini call per message) must not change.
- Reuse the existing SSE event shapes (`thought`, `tool_start`, `tool_done`, `tool_error`, `reply_delta`). Emit an event only for a step that actually ran.
- Never print or commit values from `backend/.env`.
- Report negative results; do not tune on the test split.

## Review Focus

1. The model calls a tool that is not allow-listed or misspells a name: the loop must answer with an error `tool_result` and continue, not crash, even with the injection defense switched off (tests in Tasks 2 and 3).
2. A search returns zero passages: the `tool_result` must be a text block, since an empty list of search results is invalid (test in Task 3).
3. A turn ends with `refusal` or `max_tokens`: the loop must stop cleanly with a usable reply (test in Task 3).
4. The user pasted a YouTube link in an earlier turn and asks about it later: the guard must still allow that video, but never a URL that only appeared in a model turn (test in Task 2).
5. The link sanitizer must leave code blocks, inline code and `[1]` citation markers untouched (test in Task 2).

import asyncio
from types import SimpleNamespace as NS
from backend.agent.loop import run_tool_loop
from backend.core.trace import Trace

def P(i): return {"chunk_id": f"c{i}", "doc_id": f"d{i}", "title": f"T{i}", "section": "", "source_type": "github",
                  "url": f"https://x/{i}", "score": 1.0, "text": f"text {i}", "timestamp": None}
def msg(*blocks, stop="end_turn"):
    return NS(content=list(blocks), stop_reason=stop, usage=NS(input_tokens=1, output_tokens=1), model="fake")
def text(t, cites=()):
    return NS(type="text", text=t, citations=[NS(type="search_result_location", search_result_index=i) for i in cites] or None)
def use(id, name, **inp): return NS(type="tool_use", id=id, name=name, input=inp)

def run(turns, tool_results, *, max_steps=4, check=lambda n, a, seen: None):
    seen_msgs, flags, calls = [], [], []
    async def model_turn(messages, allow_tools):
        seen_msgs.append([dict(m) for m in messages]); flags.append(allow_tools)
        return turns[len(flags) - 1]
    async def call_tool(name, args):
        calls.append((name, args)); return tool_results[len(calls) - 1]
    async def emit(_): pass
    res = asyncio.run(run_tool_loop([{"role": "user", "content": "q"}], system="s", tool_defs=[], call_tool=call_tool,
                                    check_call=check, trace=Trace(), emit=emit, max_steps=max_steps, model_turn=model_turn))
    return res, seen_msgs, flags, calls

def test_parallel_tool_calls_come_back_in_one_user_message():
    turns = [msg(use("a", "search_knowledge_base", query="x"), use("b", "search_knowledge_base", query="y"), stop="tool_use"),
             msg(text("answer", cites=[1]))]
    res, seen, flags, calls = run(turns, [{"passages": [P(1)]}, {"passages": [P(2)]}])
    last = seen[1][-1]
    assert last["role"] == "user" and [b["tool_use_id"] for b in last["content"]] == ["a", "b"]
    assert all(b["type"] == "tool_result" and b["content"][0]["type"] == "search_result" for b in last["content"])
    assert len(calls) == 2 and res.steps == 2 and res.stop == "answered"
    assert res.text.startswith("answer") and res.sources[0]["chunk_id"] == "c2"
    assert [p["chunk_id"] for p in res.passages] == ["c1", "c2"]

def test_citation_index_counts_only_search_result_blocks_across_turns():
    turns = [msg(use("a", "search_knowledge_base", query="1"), stop="tool_use"),

             msg(use("c", "search_knowledge_base", query="3"), stop="tool_use"),
             msg(text("final", cites=[2]))]
    res, *_ = run(turns, [{"error": "boom"}, {"passages": [P(1), P(2)]}, {"passages": [P(3)]}])

def test_last_step_disables_tools_and_reports_budget():
    ask = lambda i: msg(use(f"t{i}", "search_knowledge_base", query="x"), stop="tool_use")
    res, _, flags, _ = run([ask(1), ask(2), msg(text("forced answer"))], [{"passages": [P(1)]}, {"passages": [P(2)]}], max_steps=3)
